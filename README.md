### SafeWalk como sistema completo

O TCC não é só hardware, é um sistema de ponta a ponta:

- Coleta: leitura contínua de distância com sensores ultrassônicos US-100
- Tratamento: filtro de mediana e média móvel exponencial (EMA) para eliminar ruído e leituras falsas
- Decisão: controle PWM proporcional à distância, gerando vibração progressiva
- Monitoramento: envio dos dados via NodeMCU para a plataforma ThingSpeak

É a mesma lógica de captar, processar e responder que aplico em desenvolvimento de software: pensar o sistema como um todo, não só a interface.
