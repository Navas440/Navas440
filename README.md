## SafeWalk visto como pipeline de dados

O TCC é um projeto de hardware, mas o problema que ele resolve é de dados:

1. **Coleta** — leitura contínua de distância com sensores ultrassônicos US-100
2. **Tratamento** — filtro de mediana e média móvel exponencial (EMA) para eliminar ruído e leituras falsas
3. **Decisão** — controle PWM proporcional à distância, gerando vibração progressiva
4. **Armazenamento e monitoramento** — envio dos dados via NodeMCU para a plataforma ThingSpeak

É a mesma lógica de captar, limpar, decidir e monitorar que uso em análise de dados.
